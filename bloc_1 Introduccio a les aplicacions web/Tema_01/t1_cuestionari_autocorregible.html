Tema 1: Aplicacions Web · Característiques, funcionament i arquitectura

Test d'autoavaluació per a l'alumnat. Selecciona una resposta per a cada qüestió i prem el botó final per a corregir.

1. Quina tecnologia d'execució en client permet córrer codi compilat d'alt rendiment (com C, Rust o Go) dins del navegador a velocitats properes a les natives?
Explicació: WebAssembly és el format binari dissenyat per executar codi compilat de baix nivell al navegador amb rendiment natiu.
2. En una arquitectura clàssica corporativa de 3 nivells (3-Tier), quins components integren el segon nivell (Nivell d'Aplicació)?
Explicació: El nivell 1 és la presentació (client), el nivell 2 és l'aplicació/lògica (servidor web + backend), i el nivell 3 són les dades.
3. Considera la següent URL: https://server.ies.es:8443/app/items?order=desc#section2. Quina part corresponent mai és tramesa pel navegador cap al servidor web?
Explicació: El fragment (#) és gestionat exclusivament pel client/navegador per situar el document i mai s'envia a la capçalera de la petició HTTP.
4. En un patró de disseny Model-Vista-Controlador (MVC), quina és la funció clau assignada al Controlador?
Explicació: El Controlador actua d'intermediari: rep el trànsit, demana informació a la lògica de negoci (Model) i selecciona la sortida (Vista).
5. Quin canvi estructural fa que el protocol HTTP/3 solucioni el problema de Head-of-Line Blocking present en capes de transport prèvies?
Explicació: HTTP/3 utilitza QUIC sobre UDP; si es perd un paquet en un flux determinat, la resta de fluxos continuen sense quedar bloquejats a nivell de socket TCP.
6. En un model d'arquitectura desacoblada amb Single Page Application (SPA) i API REST:
Explicació: Les SPA descarreguen fitxers estàtics (JS/CSS) i consumeixen APIs que retornen exclusivament dades (JSON), renderitzant l'arbre DOM directament en el client.
7. Què distingeix a una PWA (Progressive Web App) d'una aplicació web convencional estàndard?
Explicació: Les PWAs combinen l'estàndard web amb capacitats pròpies d'apps natives (caché avançat, accés hardware, instal·lació d'icona) mitjançant Service Workers.
8. Des del punt de vista de l'administració de sistemes (ASIR), quin és un dels principals avantatges operatius d'una aplicació web corporativa?
Explicació: El desplegament centralitzat permet aplicar pegats i noves versions al servidor amb efecte immediat per a tots els usuaris sense tocar els seus llocs de treball.
9. Quin rol té una eina com PHP-FPM en una pila d'aplicació web moderna amb Nginx?
Explicació: Nginx no processa PHP de forma nativa; utilitza el protocol FastCGI per delegar l'execució dels scripts dinàmics al servei PHP-FPM.
10. Quina millora clau va aportar HTTP/2 respecte a HTTP/1.1 per a millorar el rendiment de càrrega?
Explicació: HTTP/2 va canviar el protocol textual per un format binari que permet multiplexar múltiples peticions i respostes bidireccionals en un sol socket TCP.
